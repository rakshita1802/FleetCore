1. Introduction: What Green Computing Is and Why It Matters

Green Computing (also known as Sustainable Computing or Green IT) represents the holistic study and practice of designing, manufacturing, deploying, and utilizing computers, servers, and connected sub-systems efficiently with minimal or zero impact on the natural environment. While early paradigms of green computing focused on physical hardware efficiency (such as Energy Star certified servers and low-power cooling in data centers), modern engineering mandates Green Software Engineering (GreenSE). Green software prioritizes algorithmic efficiency, lean network transmissions, and the elimination of redundant central processing unit (CPU) cycles.

The information technology ecosystem currently accounts for approximately 2% to 3% of global electricity consumption. Simultaneously, the commercial transport sector accounts for roughly 20% to 24% of global greenhouse gas emissions. When fleet telematics platforms stream millions of GPS and engine packets every hour, poorly architected software inadvertently compounds data center energy consumption. FleetCore implements an integrated dual-layer strategy: reducing real-world vehicle emissions on the road while minimizing computational resource usage on cloud servers.

2. Existing Project: FleetCore Platform Architecture

FleetCore is an enterprise-grade IoT vehicle and telematics management platform designed for fleet dispatchers, logistics coordinators, and commercial drivers. Prior to the green computing module, the system provided core logistics features across five primary functional domains:

  • Vehicle & Powertrain Inventory: Relational management of commercial assets (VIN, fuel classification, payload capacity, operational status).
  • Driver Management: Shift logging, driver licensing, safety scoring, and vehicle assignments.
  • Real-Time Telematics Stream: 5-second interval ingestion of GPS coordinates, speed, engine RPM, fuel levels, and odometer logs.
  • Geofencing & Alerts: Polygonal spatial perimeter monitoring detecting arrivals, departures, and route violations.
  • Maintenance Automation: Preventive maintenance scheduling triggered by mileage and engine diagnostic codes.

FleetCore is built on a modern full-stack architecture: React 18 with Vite on the client, Node.js and Express for the RESTful application layer, MySQL with Prisma ORM for structured persistence, and Redis for real-time pub/sub streaming. Because FleetCore already aggregates granular engine telemetry, it serves as the natural operational substrate for sustainability and eco-efficiency modeling.

3.2 Green Software Engineering Optimizations

To ensure that the sustainability analytics pipeline does not waste cloud computing resources, four software optimizations were implemented:

  • In-Memory Smart Caching with 60s Dynamic TTL: Aggregating thousands of telemetry rows across relational tables is computationally expensive. Metrics are memoized in server memory for 60 seconds, reducing query frequency from continuous requests to a single periodic aggregation. Query time drops from ~180 ms to ~3 ms (98.5% server CPU time saved).
  • Lean Query Projections (Data Minimization): Queries selectively project only the 9 required analytical columns, discarding unneeded binary buffers and timestamps. This shrinks network payloads by 78.4% (from ~148 KB to ~32 KB).
  • Single-Pass Database Aggregations: Aggregates are computed in a single pass at the database tier rather than through multiple JavaScript in-memory array operations, avoiding Node.js garbage collection overhead.
  • Green Computing Architecture HUD: A real-time telemetry HUD displays computation time, cache status, and bandwidth savings directly to administrators.

6. Conclusion and Future Directions

The FleetCore Green Computing for Sustainable Fleet Management project proves that sustainability in modern software systems must be approached symmetrically. Minimizing fuel burn, curbing excessive engine idling, and facilitating vehicle electrification addresses physical emissions on the road. Simultaneously, adhering to green software engineering principles—in-memory TTL caching, lean data projections, and single-pass aggregations—ensures that the monitoring software operates with minimal electrical and computational overhead in the cloud.

Future developments will incorporate regional electricity grid carbon-intensity awareness to optimize EV charging schedules and topographical eco-routing to maximize regenerative braking efficiency.
